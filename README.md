# Torre de Hanói Recursiva

Atividade Avaliativa 1 — Estrutura de Dados 2026-02 — UTFPR.

Professor: Clayton Kossoski

Jogo em C puro que aplica recursividade: a função `resolver()` chama a si mesma para resolver a Torre de Hanói, com condição de parada em `k == 0`.

## Como compilar e rodar

gcc \-o hanoi hanoi.c

./hanoi

## Como jogar

Escolha `1` para jogar manualmente ou `2` para ver o computador resolver. Informe o número de discos (1 a 5). No modo manual, digite os pinos de origem e destino separados por espaço (ex: `A C`), ou `Q` para sair.
